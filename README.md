# NEX Power V1

O **NEX Power V1** é um plano de energia personalizado para Windows

## Download

Baixe a versão mais recente:

**[Baixar NEX Power V1](https://github.com/RaiideenN/NEX-Power/releases/download/v1.0/NEX_Power_V1.pow)**

## Instalação

1. Baixe o arquivo `NEX_Power_V1.pow`.
2. Abra o **Prompt de Comando como administrador**.
3. Se o arquivo estiver na pasta Downloads, execute:

   ```cmd
   powercfg /import "%USERPROFILE%\Downloads\NEX_Power_V1.pow"
   ```

4. Pressione `Win + R`, digite `powercfg.cpl` e pressione Enter.
5. Selecione o plano **NEX Power V1**.

## Como voltar ao plano anterior

Abra as **Opções de Energia** do Windows e selecione o plano que você utilizava antes, como **Equilibrado**.

## Observações

- O resultado depende do hardware e das configurações do computador.
- O plano pode aumentar o consumo de energia e a temperatura.
- Não há garantia de aumento de FPS ou redução de latência.
- A importação adiciona o plano sem excluir os planos existentes.

## NEX TWEAKING

O plano também pode ser importado pela categoria **Energia** do NEX TWEAKING.
